# DevByHarsh — Personal Portfolio Website 🚀

A clean, modern and responsive personal portfolio website 
built with HTML, CSS and JavaScript.

## 🌐 Live Demo
[Click here to view](https://devbyharsh.github.io/portfolio-website)

## ✨ Features
- Clean and minimal white theme
- Animated 3D card carousel
- Smooth hover effects
- Responsive design
- Projects showcase
- Contact form
- Skills section

## 🛠️ Built With
- HTML5
- CSS3 (Animations, Flexbox)
- JavaScript
- Inter Font (Google Fonts)

## 📂 Sections
- Hero — Introduction
- Skills — Tech stack
- Portfolio — Projects showcase
- Services — What I offer
- Testimonials — Client reviews
- Contact — Get in touch
